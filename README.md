# SVIROXK — Студия веб-дизайна

Сайт-портфолио для независимой студии веб-дизайна и разработки цифровых продуктов.

## ✨ Особенности
- Интерактивный герой с частицейным фоном и Three.js анимацией
- Динамическая подсветка курсора
- Портфолио с фильтрацией и детальными кейс-страницами
- Каталог визуальных стилей с предварительным просмотром
- Конфигуратор брифа и стилей
- Адаптивный дизайн для всех устройств
- Полная типографская безопасность
- Доступность (semantic HTML, ARIA, reduced-motion)

## 🚀 Технологии
- React 19 + TypeScript
- Vite для сборки
- Framer Motion для анимаций
- Three.js для 3D фона
- GitHub Pages для хостинга
- GitHub Actions для CI/CD

## 📦 Установка
```bash
# Клонировать репозиторий
$ git clone https://github.com/sviroxk/site.git
$ cd site

# Установить зависимости
$ npm install

# Запустить в режиме разработки
$ npm run dev

# Собрать для производства
$ npm run build
```

## 🛠️ Разработка
- `src/App.tsx` — основная архитектура
- `src/components/` — UI компоненты
- `src/pages/` — страницы приложения
- `src/data/` — конфигурационные данные
- `src/assets/` — изображения и стили

## 🌐 Деплой
Проект автоматически публикуется на GitHub Pages при пуше в ветку `main`.
